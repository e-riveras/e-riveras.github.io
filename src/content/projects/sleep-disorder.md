Investigates the link between sleep quality and stress with the Sleep Health and Lifestyle dataset. The analysis is a reproducible pipeline: a Docker environment, a Makefile that rebuilds every result, and GitHub Actions for checks. Group project for DSCI 522 (Data Science Workflows) at UBC.
